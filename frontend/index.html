到时拾取审阅台

地震台站 P / S 到时拾取审阅台

  1. 点击右上角 「内置样例」 一键加载 4 台站演示数据； 或 「导入 JSON」 上传带时间戳的波形采样文件。
  2. 波形上 滚轮缩放、拖拽平移（勾选「联动」可同步所有台站）。
  3. 选择 + P / + S 放置模式后在波形上点击即可添加到时； 已有的到时线可拖动移位，两侧短柄可拖动调整 ±不确定窗。
  4. 不确定窗互不重叠的拾取会被标红为冲突； 右栏给出按 1/u² 加权的共识到时。
  5. 逐条 接受 / 拒绝 / 撤销，最后导出审阅结果（JSON / CSV）。

数据格式参见仓库 README。所有数据保存在服务端 SQLite 中。
